## // Intent / Use Cases

Design generative fonts on the three plans/font.md shaders (Runes, Script,
Sigil). Each font is a JSON file in `src/modules/glyphs/fonts/` that scenes
render through `@modules/glyphs` — e.g. a shader on a plane material for a
sign.

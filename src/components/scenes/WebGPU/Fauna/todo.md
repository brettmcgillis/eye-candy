## // Intent / Use Cases

- Generative creatures from one genome expressed as three body plans: voxel invaders, IFS blobs, bead swimmers.
- Lab rolls founders hero-style with full stats; Release drops them into a World where they eat, hunt, breed, hybridize, age and die.
- Kernel lives in `@modules/fauna` (Node-safe) so a headless CLI can share it later.

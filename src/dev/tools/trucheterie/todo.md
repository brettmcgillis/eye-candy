# // Intent/Use Cases

- Generate Trucheterie **blob field** stills through the shared render-job
  pipeline (Rorschach/Flora/Fungi's arrangement — see
  docs/flora-pipeline.md). Square and triangular grid modes are not covered
  yet; this tool renders `gridMode: 'field'` only.

## // Intent / Use Cases

- Generative single-specimen flower on black: a thin stem bursting into a lobed crown of fine lit fibers.
- Grow → bloom → hold → scatter → regrow from a new seed.
- Kernel lives in `@modules/flora` (Node-safe) so a headless stills/video CLI can share it later.

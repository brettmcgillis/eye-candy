# Stay Hunted

# // Intent / Use Cases

- This should be a small, but fully formed composition with no presets.
- The scene contains an animated rabbit model at the center
- The scene contains several long arrows with fletching protruding from the rabbits hind
- The scene contains an arrow with a long red ribbon tied to it. The ribbon uses our cloth physics and additional wind animation to enhance the scene
- The scene contains some small patches of procedurally genreated grass/foliage where the rabit model's animation appears to eat.

- grass reference: https://github.com/Faraz-Portfolio/demo-2022-grass/blob/main/src/Grass.jsx

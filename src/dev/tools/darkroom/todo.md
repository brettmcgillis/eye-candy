## // Intent / Use Cases

Media in, stylized media out: a photo, a clip, the webcam or a phone camera
through one image-driven technique (Subdivision, Kumiko, Subdivision Relief,
fractalPixelate, halftone, dither, shadingMotion), previewed live and
exported as stills or video. A technique is a folder under `techniques/`.

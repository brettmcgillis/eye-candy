## // Intent / Use Cases

fractalPixelate's recursive subdivision (quadtree / trixel tree, noise,
variance and focal drivers) as a generative piece, coloured through the
gradients.json palettes. The same kernel (`@modules/subdivision`) drives
SubdivisionCLI's PNG, WebP and plotter SVG stills.

# // Police Presence

# // Intent / Use Cases

- This should be a small, but fully formed composition with no presets.
- The scene features our police cruise engulfed in flames and smoke.
- The scene has a white background.
- The scene contains some volumetric fire emerging from the crusiers windshield, passenger and driver windwows and wrapping back around the car.
- The scene contains a smoke system emerging from the car and flames.
- The scene includes some red/blue directional point lights rotating within the lightbar to imitate the sirens active.
- The scene includes some white/warm white directional point lights positioned within the headlightss blinking on and off as if there is an alarm system going off.
- The scene includes some red point lights positioned within the brakelights as if the parking brake is on

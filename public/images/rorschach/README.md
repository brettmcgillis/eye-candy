# Curated Rorschach Media

Copy generated images or videos that need to be kept into this directory.
Unlike `output/batch/` and `output/rorschach-workbench/`, files here are not
ignored by Git and are available in the app under `/images/rorschach/`.

Generated images kept from the Rorschach workbench include their sibling
`props.json`, which records the generated preset and render options needed to
reproduce them. Kept videos are stored as MP4 files.

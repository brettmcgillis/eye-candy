## // Intent / Use Cases

Generate Apollian fractal objects in batches using the ApollianCLI — plinth stills from four bearings, the 2D slice, turntable / sweep / evolve / morph videos, and pen-plotter SVG of the slice (outlines, contours by pen, hatching); hold facets (form, slice, look, stage) to roll variations of an object you like, and promote generations to scene presets.

## // Intent / Use Cases

- Generative single-specimen fungus on black, Flora-style: a fruiting body (or a small clump) hanging over its own bare mycelium, as if pulled from the earth.
- Mycelium spreads → pins knot → caps open → spores → rot → mycelium unravels → regrow from a new seed.
- A realistic ↔ alien `mycology` dial, always stylized. Kernel in `@modules/fungi` (Node-safe), look in `@modules/fungiRender`, shared with the FungiCLI stills/video generator.

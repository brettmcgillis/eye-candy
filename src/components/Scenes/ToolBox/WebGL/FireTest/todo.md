# // Intent/Use Cases

- A toolbox scene for testing and tuning fire-related elements: Fireball, FireballSpline, Flame, and VolumetricFire.
- Provides a sandboxed environment to test these elements individually and in combination before using them in composition scenes.
- Spline-based fireball control lets me shape fire paths for use in BurningAtBothEnds, DumpsterFire, PolicePresence, FlyingHigh, etc.

## // Intent / Use Cases

- One scene, many sub-scenes of a common theme: generative music. Each preset
  is a different technique for making notes out of motion, light or rules;
  there is no windowSync here.
- Every technique shares one musical frame (root, scale, tempo, quantize) and
  one Tone.js engine (`utils/audio`): synth voices plus sampler voices
  streamed from Tone's CDN.
- Audio starts from the scene's audio toggle, which is the user gesture Tone
  needs.

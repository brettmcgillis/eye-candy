## // Intent / Use Cases

Render and plot the ghost (GhostCharacter in any GhostBuster skin) with the GhostBusterCLI — headless stills from six views, float / turntable videos and pen-plotter SVG of the cloth, rolling location, skin, pose and camera — or pose a running ghost in the Live tab (wind, gusts, cursor, orbit), pause it and capture exactly what you see.

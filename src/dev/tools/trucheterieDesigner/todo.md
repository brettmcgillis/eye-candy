## // Intent / Use Cases

Design Trucheterie blob fields by hand — paint cells of any size onto the micro-grid, erase them, and open or close each side's connectors — then save the design to `src/modules/trucheterieBlob/designs/` so TrucheterieCLI and Trucheterie3DCLI can render look variations of exactly that field.
